## Novidades
- Atualizações mais rápidas: o cache de compilação passa a ser reaproveitado de uma versão para a outra (antes cada atualização compilava o jogo inteiro de novo, uns 12 minutos)
- A etapa dos shaders reaproveita as traduções já feitas quando o tradutor não mudou (antes eram jogadas fora e refeitas a cada atualização) e só gera de novo os patches da interface que mudaram
- Esta atualização ainda compila tudo uma última vez; a partir da próxima, compilar leva cerca de um minuto e a etapa dos shaders fica bem mais curta

## What's new
- Faster updates: the compile cache is now reused from one version to the next (each update used to compile the whole game again, about 12 minutes)
- The shader step keeps the translations already made when the translator did not change (they were thrown away and made again on every update) and writes again only the interface patches that changed
- This update still compiles everything one last time; from the next one on, compiling takes about a minute and the shader step is much shorter
