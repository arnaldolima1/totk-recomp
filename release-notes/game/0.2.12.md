## Novidades
- Conquistas só valem jogando: um save copiado de outro lugar (ou restaurado de um backup) não desbloqueia de uma vez o que já estava feito nele. Essas conquistas aparecem marcadas na aba Conquistas e passam a valer quando você as fizer jogando, num jogo novo
- Créditos do projeto original e dos seus colaboradores no README

## What's new
- Achievements count only for play: a save copied from elsewhere (or restored from a backup) no longer unlocks at once what it already held. Those achievements are marked on the Achievements tab and count once you earn them by playing, in a new game
- Credits for the original project and its contributors in the README
