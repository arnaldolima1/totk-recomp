## Novidades
- O botão Instalar agora vira Jogar depois que a instalação termina
- Mods: "Adaptar mod de outra versão" gera uma cópia de um mod feito para outra versão do jogo (como a tradução e dublagem PT-BR feita para a 1.2.1) adaptada à versão instalada: os textos são juntados mensagem por mensagem, a tabela de tamanhos é refeita e o que é novo na versão fica no original
- Um mod de outra versão mostra o botão "Adaptar para <versão>" direto na lista

## What's new
- The Install button now turns into Play once the install is done
- Mods: "Adapt a mod from another version" makes a copy of a mod made for another game version (such as the PT-BR translation and dub made for 1.2.1) adapted to the installed one: the text is merged message by message, the size table is rebuilt and what is new in the version stays as it was
- A mod from another version shows an "Adapt to <version>" button right in the list
