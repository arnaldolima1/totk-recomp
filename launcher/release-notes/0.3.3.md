## Novidades
- O jogo abre sem a janela de terminal atrás dele
- Aba Mods com visual novo: um botão para adicionar o .zip e cards com o tipo do mod (Tradução e dublagem), o que ele muda e o idioma
- A tradução PT-BR é reconhecida ao adicionar o .zip: se ela for de outra versão do jogo, o launcher converte e liga sozinho, sem passo extra
- Com a tradução ligada, o idioma do jogo aparece como Português (Brasil) no lugar do inglês, e o jogo já é configurado nele

## What's new
- The game opens without a terminal window behind it
- New look for the Mods tab: one button to add the .zip, and cards with the mod's kind (Translation and dub), what it changes and its language
- The PT-BR translation is recognized when its .zip is added: when it was made for another game version, the launcher converts and turns it on by itself
- With the translation on, the game language shows as Português (Brasil) in place of English, and the game is set to it
