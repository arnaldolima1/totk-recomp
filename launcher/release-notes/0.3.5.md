## Novidades
- Em instalações novas, o launcher fecha sozinho quando a janela do jogo abre, liberando memória enquanto você joga (dá para mudar em Configurações → Fechar o launcher ao jogar)
- Nova versão do jogo disponível (0.2.3): câmera no mouse mais suave, janela sem borda, aviso de compilação de shaders e suporte ao controle de PS5 (gatilhos adaptáveis e barra de luz)

## What's new
- On new installs, the launcher closes by itself once the game's window opens, freeing memory while you play (Settings → Close the launcher when playing changes it)
- A new game version is available (0.2.3): smoother mouse camera, borderless window, a shader compile notice and PS5 controller support (adaptive triggers and light bar)
