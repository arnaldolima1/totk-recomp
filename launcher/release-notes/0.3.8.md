## Novidades
- Fechar o launcher durante a instalação agora encerra a instalação junto; antes ela continuava rodando escondida e a próxima instalação ficava presa no início dos shaders
- Uma nova instalação encerra sozinha qualquer instalação antiga que tenha ficado rodando
- A etapa dos shaders mostra o andamento dos patches da interface ("3 de 13 conjuntos") e ficou mais rápida
- O jogo 0.2.15 corrige a digitação nos campos do multijogador, o som das conquistas e as conquistas de corações e vigor que desbloqueavam no prólogo

## What's new
- Closing the launcher during an install now stops the install too; it used to keep running unseen, and the next install stuck at the start of the shaders
- A new install ends any older one still running on its own
- The shader step shows the progress of the interface patches ("3 of 13 sets") and is faster
- Game 0.2.15 fixes typing in the multiplayer fields, the achievement chime and the hearts and stamina achievements that unlocked in the prologue
