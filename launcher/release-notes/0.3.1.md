## Novidades
- Botão "Buscar atualizações" em Configurações > Launcher e em Sobre: procura versão nova do launcher e do jogo
- A instalação não recusa mais a pasta quando você mudou configurações ou adicionou mods antes de instalar
- O launcher não usa mais a pasta do código-fonte como instalador por engano; o botão Baixar fica sempre disponível

## What's new
- "Check for updates" button in Settings > Launcher and in About: looks for a new launcher and a new game version
- The install no longer refuses the folder when you changed settings or added mods before installing
- The launcher no longer picks the source code folder as the installer by mistake; the Download button stays available
