## Novidades
- Launcher do TotK Recomp: instala, atualiza e abre o jogo a partir dos seus próprios arquivos (base + atualização 1.2.1 ou 1.4.3 e prod.keys)
- Baixa o instalador do GitHub sozinho e confere o arquivo, do repositório oficial ou de um alternativo
- Botão para achar o jogo base, a atualização e o prod.keys numa pasta
- Configurações do totk.ini: resolução, escala 3D, FSR, VSync, limite de FPS, idioma, controles e teclas, com presets de qualidade
- Aba Mods: mods no formato de emulador (pasta com romfs ou .zip), juntados e verificados para o recomp
- Avisa quando sai uma versão nova do jogo

## What's new
- TotK Recomp launcher: installs, updates and starts the game from your own files (base + the 1.2.1 or 1.4.3 update and prod.keys)
- Downloads the installer from GitHub by itself and checks it, from the official repository or an alternative one
- A button that finds the base game, the update and prod.keys in a folder
- totk.ini settings: resolution, 3D scale, FSR, vsync, frame rate limit, language, controls and keys, with quality presets
- Mods tab: emulator-format mods (a folder with romfs, or a .zip), merged and checked for the recomp
- Tells you when a new game version is out
